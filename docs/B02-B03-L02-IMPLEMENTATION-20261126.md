## 手册要求

加载失败必须区别于真正空结果；旧异步失败不能覆盖新搜索。
本地化不得改变技术值、数据绑定、禁选、样式或业务原文。
文档检索使用页面实际可见文字，保留原始模型/Markdown 来源。
受控源码和本地 DOM 验收不替代真实业务、多角色或共享运行版证据。

## 本地实现观察

- 人员选择器原先让加载异常传播为未处理拒绝，随后显示“暂无数据”。
  现在显示双语失败提示，按相同查询/页码重试；旧请求失败不覆盖新状态，
  翻页失败保留原记录。原 helper/控制器文案和同插件 BEM 样式修复作为
  已审查的必要历史依赖交付；新增重试区对齐样式。
- 动态码表用对象展开复制英文显示项，丢失实际 `CodeListDataItem` 的原型、
  非枚举 `$origin` 与 getter。最小提交保留属性描述符/原型，只覆盖显示 text，
  并支持精确模型定义的非主状态选项。原 alias/订阅及旧测试差异仍留工作区。
- 文档页面正确显示特殊字符，原搜索却使用 HTML 编码和 Markdown 原文。
  现在复用已有 Docsify 解析器，从未插入页面的模板提取 `displayBody`，
  供检索和摘要使用；原始正文、schema、DTO 和路径保持原样。
