# 文档与业务文案实现

检查点：2026-11-26，Asia/Singapore。三个独立 agent 分别处理业务文案、
DTO 文档生成和 Docsify 交互；主线核对提交依赖、回执和源字节。
本轮没有操作 Docker、业务 API、共享数据库、共享 dist 或运行服务。

## 手册要求

工作项、迭代、基线、测试执行和评审提示须保留生命周期语义。显示翻译不得改变
技术键、状态、路径或用户内容。Development/API Reference 独立于手册目录；
源码、静态候选和真实宿主全流程分别记录，不互相代替。

## 本地实现观察

- 新增 96 个实际模型英文词条，修正测试用例重要程度的既有误译；
  对十个真实消费者保留 `level` 和原代码表绑定。
- 确认/成功提示的翻译支持原先只在脏工作区中。最终只提交
  `displayKeys` 中 `confirmMsg`、`successMsg` 两行必要依赖，其他旧适配不纳入。
- DTO 格式中的实体字符、表格分隔符、反引号和换行不再显示为编码文本；
  普通标签标点不再被 Markdown 改为强调或链接。
- 搜索输入组合期间保留 Enter，组合结束重新过滤。实际 Chromium 验证发现
  DOM0 composition 属性赋值未生效，最终使用事件监听器。

本轮文档源提交同时包含此前尚未提交的正文搜索、查询保持、错误重试和样式接线：
它们属于同一任务、是本次输入法修复依赖，已整体审查和运行；
没有把整个差异都称为本轮新增。其他仓库和文件的原有修改保留。
