# D01 框架源码双构建与交付字节验证（2026-11-26）

本轮从 `ibiz-app-hub` 的真实当前源码执行七个包的原有 `npm run build`，修复两项实际构建缺陷，并在两个新私有工作目录中得到完全相同的交付字节。r9 保留构建修复的完整证据；后续 B03 生命周期补丁冻结后，新 r10 再次完成双 build 和独立全产物校验。七个包合计只属于 D01 最低范围中的一个 `app-framework` 组件。D01、D02、D03、O01 的顶层验收仍未关闭；本文不修改任务总表或剩余数量。

## 手册要求

源码闭包、镜像与服务字节对应、运行输入闭合、干净主机重建是独立能力；PLM 使用手册学习不能关闭这些任务。最低 12 组件范围沿用 `harness-required-source-gates.mjs` 的 `REQUIRED_D01_COMPONENTS`。缓存依赖、命令退出码为零、局部编译或同名新版分支不能代替当前组件完整源码构建，更不能代替递归依赖/工具链源码闭合和实际服务验收。

本轮没有使用 Modeling 的 `packages-latest` 分支替代 canonical AppHub 源码，也没有把已有分发包复制出来冒充新构建。

### 已修复的真实缺陷

原 `rollup-plugin-scss@4.0.1` 按异步 transform 完成顺序收集样式，导致 r5 的三个 CSS 文件两遍字节不同。`fixtures/frontend-scss-order-patch.mjs` 对私有工具副本应用可审查补丁：从单个真实 bundle entry 按 `importedIds` 深度优先顺序访问静态图，再按声明顺序访问延迟图；共享模块和环只访问一次，无法从图到达的已收集样式会明确失败。真实缓存插件配合 Sass 的回归先证实原 collector 在相反完成顺序下输出不同，再证实修复后均为 `.same{color:red}.same{color:blue}`，保留源导入的层叠先后。不是事后对 CSS 规则排序。

只修改私有 CLI/CLI-core/SCSS 工具目录中的解析和 collector；原依赖缓存未变。SCSS CJS 原字节 SHA-256 为 `3b44d0b7293c4cfde2c0bd058f3d6f5acb057364f2db984f8fe1bca505361cea`，私有修复后为 `2b42b67802df3c40ff0a310841976ea5052d7cba2ddc8252a85cc6610af7f503`。因此结果称为“canonical 包源码配合显式修复的私有工具链可重复构建”，不声称原工具链可重复。

r8 的 dist 已一致，但独立校验扩展到全部声明/ESM/CJS 后发现八项差异：组件从 `@ibiz-template/core/out/utils/namespace/namespace` 深层导入，`preserveModules` 将 first/second 临时目录写入生成的导入路径。三个最小 canonical 源码变更将 `defaultNamespace` 从 core 公共入口导出，并让 DRTab、fullscreen 从该入口导入。常量仍为 `ibiz`，未改变业务值或命名空间计算。两项真实源消费者测试从 0/2 失败变为 2/2 通过。

新的 components 需要相匹配、包含该公开导出的 core；不能单独将这些 components 发布到旧 core。本轮没有发布七包，也没有修改现有服务的导入映射。

### 独立校验入口

新增 `verify-owned-frontend-source-closeout.mjs`。最终审查后的版本要求调用方同时给出 producer 回执和 plan 的精确 SHA-256，并校验封存 runner 及其 CSS 配方依赖后，重新枚举两个工作目录内全部 `dist/out/es/lib`，包含 JS、CSS、声明及映射文件。完整产物和复制出的 dist 分别必须匹配 producer 原来记录的全文件集指纹；两遍后来同时缺文件或同时被改写也不能通过。

校验器用原构建缓存中按字节绑定的 TypeScript 解析器读取七个 SystemJS 入口及相对 chunk。所有可达生成模块必须匹配 producer 的 dist SHA-256 并包含真实 `System.register`；复制入口不能脱离原 workspace dist。import map 也必须匹配原 plan。bare external 按该真实 map 定位、读取和绑定当前本地文件 SHA-256。此检查只到直接外部运行文件，不声明完整递归运行依赖闭合、浏览器执行或运行服务等价。
