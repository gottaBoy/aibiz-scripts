  文档或模拟发送器不能替代这些外部条件。

  不通过删除“未启用”提示完成任务。

  不能用 `UPDATE_TIME` 猜实际结束，不能默默把零分母替成业务上有效值。
- 自有运行环境：旧 26 个验证容器已退役。旧回执不表示环境还在；一次只安排一套环境，
  不把共享库与历史数据当自有夹具，不使用已停用的共享 runtime replay。
- 源码模型是运行 bind 输入。虽然未显式重载/替换共享服务，源码变更是否被懒加载
  仍需通过当前服务字节/动作核验，不能笼统写成“模型一定未生效”或“已经上线”。
