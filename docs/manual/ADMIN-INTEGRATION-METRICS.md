## 管理员合同

来源：`f2188007621773ab945652190f0b2d11`、`648b87f426382d9b5cba1a2a127b8f09`。

- 一个组织只能有一名组织所有者；组织管理员可以有多名，其管理权限由所有者分配。不要把任意管理员账号当作所有者等价物，也不要从菜单可见性推导服务端授权。
- 产品、项目、测试、知识、协作等子产品管理员只管理自己的子产品配置，不自动获得整个组织的成员、组织架构或角色管理权限。
- 组织、团队、具体资源成员角色分别建模并验收。组织管理员、团队管理员、资源管理员不能因为名称相似而共用一个无条件超级权限。
- 对角色变更、成员移除、归档、删除与恢复同时检查 UI 和直接 API，保存前后重新登录另一角色复核，防止缓存权限成为唯一依据。

## 第三方集成合同

来源：`759635aba2cfd4caa5f99d4f12eb4dc2`。本章具体说明的是钉钉与企业微信，不是对 GitHub、GitLab 或全部外部系统已支持的证明。

### 两条独立身份链

| 事项 | 钉钉 | 企业微信 |
| --- | --- | --- |
| 外部应用 | 在钉钉开放平台创建 PLM 应用 | 在企业微信后台创建 PLM 应用 |
| 平台接入 | 设置唯一接入标识、钉钉预定义类型与实际应用参数 | 设置唯一接入标识、企业微信预定义类型与实际应用参数 |
| 凭据 | 使用真实 `AccessKey`、`SecretKey`、`AgentId` | 使用真实 `AccessKey`、`SecretKey`、`AgentId`，其中 `AccessKey` 是企业 ID |
| 用户同步 | 显式触发机构用户同步，核对完成结果；失败时检查服务日志与 IP 白名单 | 显式触发机构用户同步并核对结果 |
| 系统绑定 | 系统配置必须引用同一个接入标识 | 系统配置必须引用同一个接入标识 |
| PLM 用户 | 同步外部用户不会创建 PLM 用户；单独创建 PLM 用户，以一致电话号码匹配 | 同步外部用户不会创建 PLM 用户；外部接口不提供电话，需在 PLM 用户上选择对应企业微信用户 |
| 消息 | 身份映射与配置齐备后，验证真实系统消息送达目标钉钉账号 | 显式用户绑定后，验证真实系统消息送达目标企业微信账号 |
| 工作台 | 配置网页应用、安全与分享配置，验证携带企业上下文的移动入口 | 配置应用主页、网页授权/JS-SDK 可信域名和企业可信 IP，验证工作台入口 |

手册的后台 `32666` 和移动端 `30260` 只是部署示例端口，不能直接认定本机相应界面可用。集成参数必须来自当前受控环境，不在文档、截图、测试回执或 Git 中写入秘密。公网授权域名、可信 IP、回调与重定向规则要以真实部署为准，不能为了显示“同步成功”绕过身份校验。

集成状态应至少区分“未配置”“已配置待验证”“同步失败”“同步成功但未绑定 PLM 用户”“通知验证通过”。只保存配置、返回同步完成文字、使用模拟发送器，均不能关闭真实联调任务。没有真实凭据或外部账号时记录阻塞条件，不伪造成功。

## 效能度量合同

来源：`a93a54b5b3e65514fa76df7a44532c04`、`5d12991bd3c2e5b5321ff13a9eb84113`。

研发效能覆盖交付效率、交付质量和持续交付能力，不能只用工作项数量或工时当作综合效能结论。概念页提及构建、提交、集成与部署指标，不等于本文已定义它们的数据来源或集成实现。

### 视图、仪表盘与报表

来源：视图 `01a6f0bff8e01ec366d19ef4c4e80f00`、仪表盘 `43eaf4f1c9fded017440ef1eb6fde698`、报表 `5b0f2262315eee58efbcfe2a45768904`。

- 组织视图创建要求管理员及“新建视图”权限；团队视图要求该团队管理员；个人视图允许每个账号创建。名称和唯一标识必填。
- 组织/团队公开视图面向相应组织/团队成员可见，但只有视图成员可编辑；私有视图仅成员可见、可编辑。个人视图始终私有，不能改为公开。
- 创建流程包含所属、可见范围、基本信息、成员与默认仪表盘。成员可从成员、部门、团队加入；角色调整与移除需要独立授权。
- 支持按名称搜索、全部/星标/最近访问筛选、名称/更新时间排序、星标与切换。设置中维护成员、基本资料、移动与删除；移动后必须重新计算目标所属的可见范围及成员。
- 仪表盘从模板创建；报表先存在于报表管理再加入仪表盘。添加、移除、拖放、缩放后只有保存布局才应持久化；全屏、刷新、编辑不能意外改变布局。
- 报表按数据集及自定义分组/类别组织；支持名称搜索与表头显示设置。分组和类别支持创建、重命名、删除、排序；类别可跨分组移动，报表可重新分类，类别支持表情图标。
- 删除类别、分组或仪表盘上的报表引用，不应未经明确合同就当作删除底层业务数据或全部报表实体。

### 指标口径

来源：`546938b70ecdf7fbccaa3b2ce265d2ec`，包含 43 个指标条目。以下是改写的实现约束，公式中的集合应先应用同一权限、业务范围与筛选条件。

| 指标族 | 必须保留的口径 |
| --- | --- |
| 数量 | 工作项、迭代、项目、测试用例、测试计划、执行用例、发布、工单、产品需求各按对应业务对象计数，避免关联表联接放大 |
| 需求吞吐量 | 仅计已完成或已关闭的需求 |
| 工作项完成率 | 完成或关闭数 / 工作项总数 |
| 工作项按期完成数与率 | 完成/关闭时间不晚于截止时间；比例分母为完成/关闭工作项，不是全部工作项 |
| 工作项逾期完成数与率 | 完成/关闭时间晚于截止时间；比例同样以完成/关闭工作项为分母 |
| 未完成工作项逾期数与率 | 排除完成/关闭项，当前时间超过截止时间；比例以未完成工作项为分母 |
| 需求/缺陷平均生命周期 | 各阶段停留时长合计 / 相应需求或缺陷数，不能直接替换成创建到当前的年龄 |
| 故事点与工时 | 分别汇总故事点、预估工时、登记工时和剩余工时，不能混用度量单位 |
| 预估偏差率 | 对每个工作项先求 `abs(登记工时 - 预估工时) / 预估工时`，再取算术平均；不是总实际与总预估的相对误差 |
| 预估差异工时 | 预估与实际登记工时之差的绝对值；聚合层级需写明，不能自动等同于预估偏差率 |
| 缺陷 DI | 致命、严重、一般、建议的权重依次为 `10、3、1、0.1` |
| 缺陷重开率 | 从完成/关闭状态重新打开的缺陷数 / 总缺陷数 |
| 属性分布 | 缺陷占比、工单占比、产品需求占比按各自属性分组后除以同范围总数；工时类别占比按工时量而非条目数 |
| 测试平均交付周期 | 测试计划交付时长总和 / 已交付计划数 |
| 测试执行率 | 计划中至少执行过一次的执行用例数 / 计划全部执行用例数；重复执行不增加分母或重复计数 |
| 测试执行通过率 | 最后执行结果通过的用例数 / 计划全部执行用例数，不是通过数 / 已执行数 |
| 项目风险占比 | 指定风险状态项目数 / 总项目数 |
| 项目平均生命周期/进度 | 分别对项目的结束减开始时长、项目进度取平均 |
| 需求覆盖率 | 已关联测试用例的需求数 / 全部需求数，一个需求关联多用例仍只计一次 |
| 迭代延期数与率 | 延期迭代数；比例按总迭代数作分母 |
| 迭代按时交付数与率 | 按时结束的迭代数；比例按已结束迭代总数作分母，不含未结束迭代 |
| 发布平均生命周期 | 原文为阶段结束日期、初始日期与发布数的组合，括号不清晰；确认阶段时长聚合口径后再实现，不能按运算符优先级直接解释原文 |

所有比例必须明确空分母、缺失时间、零预估、时区、精度、百分比格式、归档/删除对象及重开对象的处理策略。手册没有给出统一零分母政策，不允许静默显示 100% 或用 1 替换分母后当作手册定义。

## 协作空间合同

来源：概览 `1366d9e018ce225e5e882f41504fa391`、话题 `03c1b3ad9c48552abc274f55f7b4a1f8`、话题设置 `f60f577a236120f4ccdfca8ec7ffc63e`、讨论 `0f194bfb2898e48392469bc605ea67f7`。

- 话题是讨论的容器。创建包含所属组织/团队、名称、可见范围、唯一标识与描述；列表支持分组访问和星标。私有话题成员支持角色分配。
- 组织公开话题允许组织成员发起讨论；团队公开话题允许该团队成员发起讨论；私有话题需要话题成员且具备发起权限。公开可见并不表示对组织外匿名用户开放。
- 讨论支持标题、富文本内容、附件和邀请关注；支持回复、评论、回应表情、点赞与置顶。列表支持筛选、搜索和排序；回复列表支持内容搜索，详情展示作者统计、状态和参与人。
- 关闭讨论会禁止写回复，允许有权者再次打开；关闭不是删除。移动讨论要改变归属话题并重算权限；不能继续由旧话题的用户缓存读取私有内容。
- 删除讨论先进入话题回收站，支持单个或批量恢复。话题移动时其讨论一并跟随；话题可归档、激活、删除、恢复，各状态应在相应管理列表可核查。
- 概览提及目标对齐、进展与复盘，但详细页面只规定话题和讨论。不得由此声称完整目标/OKR 周期、层级对齐、评分和复盘已经有完整合同或实现。

## 多角色流程与负向验收

这些是后续验收清单，不是本轮已执行结果。每次执行记录角色、资源归属、前置数据、请求及响应、页面结果、console/network 错误和清理回执。中英文界面均应覆盖名称、提示、状态和富文本/表情回读。

| 编号 | 角色与完整流程 | 必须包含的负向/边界检查 |
| --- | --- | --- |
| A1 | 所有者分派组织管理员 -> 管理员维护团队/成员/职位 -> 单个及批量改角色/移除 -> 重新登录复核 | 第二所有者不能被任意创建；未分派权限的管理员、子产品管理员与普通成员不得调用组织管理 API |
| A2 | 产品/项目/测试/知识/协作管理员分别设置资源管理员 -> 归档 -> 激活 -> 删除 -> 恢复 | 非成员不得被无条件提升；归档资源不应直接进入详情；越域管理员和普通成员直接调用同一 API 应被拒绝 |
| A3 | 项目管理员修改全局工作流/属性/组件模板 -> 保存 -> 新建同类型项目 -> 核对初始化 -> 单独修改已有项目 | 旧项目不被静默覆盖；系统属性/状态不可删除；非法状态迁移、无权配置和未保存规则不得生效 |
| A4 | 有权者配置操作/属性通知 -> 成员触发事件 -> 目标用户验收通知 | 不重复投递，不泄露给无权者；手册 TODO 的提醒与属性权限不能只凭已有表单关闭任务 |
| I1 | 外部平台管理员创建钉钉应用 -> 配接入与系统绑定 -> 同步 -> 人工建 PLM 用户/对齐电话 -> 真实消息 -> 工作台进入 | 错电话、缺用户、错接入标识、无白名单/无效凭据时明确失败且不发给他人；同步不能偷偷创建 PLM 用户 |
| I2 | 外部平台管理员创建企业微信应用 -> 配可信域/IP -> 同步 -> 人工建 PLM 用户并绑定外部账号 -> 消息 -> 工作台进入 | 未绑定或错误绑定不得以手机号猜测身份；越组织映射被拒；缺可信配置的失败要可诊断 |
| M1 | 组织管理员、团队管理员、普通成员分别创建各自允许的视图 -> 加成员 -> 建默认仪表盘 -> 建/分类报表 -> 添加/调整布局 -> 保存 -> 刷新 | 普通用户不能创建组织/他队视图；非成员只能读公开视图；私有视图不泄露；个人视图不能公开；未保存布局不误写入 |
| M2 | 视图管理员移动视图并调整成员 -> 新旧范围账号分别复核 -> 删除视图 | 老所属身份不能保留越权；新所属不越界；删除展示引用不误删来源数据 |
| M3 | 业务成员生成需求、缺陷、工时、计划执行与迭代数据 -> 报表筛选 -> 独立算例对账 -> 钻取明细核对 | 用例重复执行、联接重复、零预估、空分母、完成/未完成混用、时区边界和删除对象均有算例 |
| C1 | 话题管理员建组织公开/团队公开/私有话题 -> 设置成员角色 -> 成员发起、回复、评论/表情 -> 关闭/重开 -> 搜索 | 组织外、他队、非私有成员及无发起权限成员通过 UI/API 均不可越权；关闭后写回复被拒 |
| C2 | 有权者移动讨论/话题 -> 新旧范围复核 -> 删除 -> 回收站单个/批量恢复 -> 归档/激活 | 旧话题不残留私密内容；附件和回复权限随归属改变；归档/删除不可被直接链接绕过 |

### 最小数值验收样例

- DI：四档缺陷各 1 个，结果为 `14.1`，不能按未加权数量 `4` 展示。
- 预估偏差：两项预估为 `2、8`，登记为 `4、8`，平均个体误差为 `50%`，不能算成汇总差异的 `20%`。
- 测试计划：4 个用例，两个已执行，其中一个最新通过，结果为执行率 `50%`、通过率 `25%`；同一用例再执行不能把分母从 4 变成 5。
- 按期：5 个工作项、2 个已完成且 1 个按期，按期完成率为 `50%` 而非 `20%`；4 个迭代、2 个已结束且 1 个按时交付，按时交付率同样为 `50%`。
- 对零条目、零预估、无截止时间以及重置执行结果后的历史执行标记分别给定决策和期望值；这些未明确项不能由上面的普通算例代替。
