## 证据边界

- **手册要求**：下文标有 T/K 页号的规则来自本次 42 页正文；不得把它们自动当作当前运行行为。
- **本地观察**：仅限下文列出的实际读取过的模型、逻辑定义与测试代码。文件存在、动作注册或节点命名不等于实现正确、权限生效或部署已更新。
- **待验收**：下文正向和负向流程均是必须执行并留证的测试要求；本轮没有运行浏览器、接口、数据库、容器或全量测试。
- 手册图片尚未逐张核验。正文、标题和表格完成阅读不等于图片中的控件、布局、状态细节已经确认。
- 权限应同时覆盖列表、搜索、详情、关联选择器、批量动作、导出、附件和分享入口；菜单隐藏不能代替服务端拒绝。
- 验证要使用隔离且可清理的数据、独立身份及新会话读回；不得为让报表或状态通过而直接修库。

## 测试管理规则

### 测试库与权限

- 测试库是用例、评审、计划和基线的边界。组织与团队所属不能仅替换名称；创建团队所属测试库要求当前账号具有该团队管理员身份。名称必填，标识承担用例编号前缀职责。[T01-T04]
- 公开测试库对所属组织或团队成员可见，但可见不等于可编辑；编辑限测试库成员并仍受其操作权限约束。私有测试库只有库成员可见、可编辑，不能把私有库暴露给同组织非成员。[T03]
- 添加成员支持个人、部门、团队；默认角色为普通成员。移除成员后不能继续以残留角色、旧会话或缓存执行库内操作。公开库的移除成员可能仍有所属范围阅读资格，不得误写为必然完全不可见。[T04]
- 移动库需重审所属、可见范围和成员。归档后由管理员激活，删除后由管理员恢复；归档、逻辑删除、恢复、永久删除不可混为同一动作。[T04]
- 模块可新增、改名、排序、调整层级、收展一级子模块；未分模块用例有独立集合。模块删除如何影响子模块及用例，手册未明确，不能自行补上级联删除。[T06]
- 测试库组件开关是单库设置，不应影响其他库；关闭组件后的旧链接、后台动作可用性须另验，不能据开关推断授权。[T04]

### 用例、版本与基线

- 用例至少保留标题、维护人、类型、P0-P4 重要程度、前置条件、步骤和预期结果。详情编辑、表格行编辑及批量编辑必须遵守相同字段和权限规则。[T05,T07]
- 复制可指定目标库/模块且支持批量；移动改变所属而不是复制。跨库操作须同时检查来源读取、目标写入和模块归属，不能借批量操作绕过权限。[T07]
- 用例模板是库内复用资产；删除模板不可恢复，但不得删除此前通过模板创建的用例。模板应用后不得形成修改模板即可静默改动已有用例的共享实例。[T04,T11]
- 用例删除可在回收站恢复；不要把恢复误实现为创建新业务用例或丢失原关联。恢复后的版本、关联、权限和所属模块需要专门留证，手册未给完整恢复细则。[T07,T10]
- 新建版本保留历史内容；**恢复历史用例版本应以历史内容创建一个新版本**，不是覆盖或回写历史快照。编辑版本信息、恢复版本均由“新建用例版本”权限点控制，不能仅检查通用编辑权限。[T08]
- 版本对比覆盖基本属性、自定义属性、步骤、附件和关联数据，支持切换版本及隐藏相同项；多行文本新增/删除需要可区分，不能只比标题或版本号。[T08]
- 进行中计划应提示已规划用例的新版本。提示更新不等于自动升级，不能让用例最新版本静默替换既有执行、评审或基线版本。[T08]
- 基线名称不能重复；新基线为打开状态，可规划最新或历史用例版本。设立完成后内容冻结。[T16]
- **基线特例**：设立时，若所规划版本仍是该用例的最新版本，应为用例创建后继版本并标记基线创建原因；基线必须继续指向设立时版本。规划的是历史版本时，不得无条件额外创建版本。[T16]
- 基线默认与各用例最新版本比；对另一基线比对时，新增指对方独有，删除指当前独有，修改指同一用例版本不同。不能颠倒比较方向；共同用例支持具体版本内容比较。[T16]
- 用例详情应能追溯当前版本最近规划的基线，也能查询所有版本所在基线及状态。[T16]

### 评审状态

- 评审计划、评审阶段、单条评审结果和用例整体状态是不同对象，不得共用一个状态值推导全部状态。[T17-T21]
- 手册要求新用例待评审；规划进评审后转为评审中。同一用例可进入多个评审计划，不能用“一个用例只能在一个计划”简化关系。[T19]
- 未开始的评审计划允许添加内容；正在评审且当前阶段评审人为当前测试人员时，才能记录通过/未通过与意见。批量评审和继续下一条不能跳过阶段、身份或单条权限。[T19,T20]
- 移出评审计划要保留评审记录，之后允许重新选入；不能删除历史来模拟重新开始。[T19]
- 完成当前阶段与完成整个计划要分开；最后阶段完成后计划已完成。手册明确已完成计划不能再切换到其他状态。[T18,T20]
- 评审历史至少可追溯阶段、结果、时间，并保留所评审版本；后续改用例不能改写此前评审的内容证据。[T21]

### 计划、执行与报表

- 测试计划按分类可关联项目、迭代或发布；未开始到进行中，再到已完成。用例可进入多个计划，可移入未开始或进行中的计划；已完成计划的写入边界不能由 UI 按钮缺省状态决定。[T22,T23]
- 执行用例不是原始用例：记录执行人、优先级、步骤实际结果、步骤结果、整体结果、结果附件及所用版本；编辑原始用例仍需对应编辑权限。[T24]
- 通过表示可执行且未发现缺陷；失败表示实际执行后发现缺陷；受阻表示无法正常执行；跳过表示本轮不适用且未执行。不得把跳过或受阻自动计为通过。[T24]
- 单条/批量执行、保存并下一条、上一条/下一条、重置为未测都必须有一致的数据语义。重置不是删除原始用例；如何保留执行审计须另行确认。[T24]
- 缺陷可新建或关联已有缺陷，新建缺陷进入项目缺陷流程。取消关联不得删除缺陷；计划默认看本计划提交的缺陷，可另纳入关联迭代缺陷，必须避免混淆来源及重复计数。[T24,T26]
- **通过率分母是本计划规划的用例总数**，不是已执行数、通过加失败数或执行尝试次数；零用例时展示策略尚未明确。例：四条规划用例分别通过、失败、跳过、未测，通过率应为 25%，不是 50%。[T22,T28]
- **执行历史显示次数与执行事件次数不能混用**：同用例在同一计划多次执行，详情历史仅展示该计划最近一次信息；仍须展示计划、结果、时间、执行人、执行版本。不能据历史显示一行推断只执行一次。[T25]
- 报表要分别定义新增/变更用例、规划次数、维护人/重要程度/类型/评审结果分布、执行结果、计划对比、每日执行次数与结果趋势、优先级及执行人分布。规划次数不是去重用例数；每日次数不得直接用“当前 RUN 行数”替代，重复执行、重置和跨天口径必须留待明确。[T28]
- 我负责的按计划负责人，我参与的按执行人，进行中的按账号所在测试库及计划进行中状态筛选；不能把三个视图都退化为当前库全部计划。[T29]
- 导入以下载模板及字段规则为依据；导出应继承筛选与权限边界。排序、搜索、筛选重置、列宽及表头设置也属流程，但不能替代用例业务验收。[T09,T12]
- 产品需求、项目工作项、附件的关联与解除要保持对象本身；用例可关联不同项目的多个工作项。关注、评论、回复、@ 成员与提及工作项应绑定正确用例和通知对象，不能扩大接收者的读取权限。[T13-T15,T30]

## 知识管理规则

### 空间、页面与共享权限

- 空间保留所属、名称、可见范围、标识、描述和成员；组织/团队成员选择不能泄漏其他范围的人或页面。空间移动、归档、删除与管理员恢复是不同流程。[K01,K02,K10]
- 空间管理员管理空间及页面；普通成员可操作页面但不能操作空间设置；只读成员可浏览并将页面与其他资源关联。**只读不是完全无操作，也绝不是允许正文编辑**。[K10]
- 共享权限分为空间成员、非空间成员和公开链接；非空间成员可被授予仅查看或可编辑，并可选择是否带子页面。拥有一个页面权限不等于拥有整个空间或兄弟页面权限。[K06,K10]
- 页面、空间共享需独立验证密码、有效期、关闭共享、密码刷新以及默认全部/指定部分页面。空间共享默认含全部页面；选择子集后，搜索、直接地址、附件和子树不能泄漏子集外内容。[K02,K06,K10]
- “与我共享”应展示授权、共享人和共享时间；最近访问包含查看/编辑时间与所属空间；收藏可取消。任何历史记录、收藏或旧通知都不能维持已撤销的访问授权。[K03]
- 页面锁定后，手册规定任何人不能编辑。实现必须让正文编辑、发布、批量写、共享编辑及其他可改内容动作遵守锁，不得暗设管理员绕过。解锁主体、能力范围与历史恢复是否算编辑，手册未定义。[K04]

### 草稿、版本与内容

- 页面有草稿与已发布内容两个阶段；未发布内容进入草稿，发布后在空间可见并移除对应草稿。已发布页面再次编辑不能让未发布草稿通过普通预览或共享链接提前泄漏。[K04]
- 页面树可拖动建立层级；新建、模板新建、重命名、复制和移动应保持空间、父节点和排序一致。复制可选择携带子页；删除页面连同子页面删除，回收站支持单条/批量恢复。[K04,K11]
- 跨空间复制/移动需目标权限、父节点合法性和子树权限检查；禁止循环父子关系、部分失败后无记录残留、将私有草稿连带公开。删除后子树恢复如何处理原父节点缺失，手册未明确。[K04,K11]
- 正文支持 HTML、Markdown、Excel 三种格式。HTML 编辑包括文字格式、撤销重做、待办、链接、图片、表情、提及成员、表格行列、引用、分割线、代码块、附件和 HTML 内容；不能以一个普通 textarea 声称全部完成。[K05]
- 作为安全验收要求，HTML、链接、网络图片、附件和代码必须检查脚本/危险协议与访问控制；这些安全策略未在手册详述，不可宣称手册已定义具体清洗规则。[K05]
- 页面评论与选区内容评论是不同入口；需支持提及、通知、关注级别及所声明的富文本能力。选区变化、版本变化后评论锚点如何定位应另验。演示、最小化、大纲导航及页面树宽度均应可正常进出，不改业务内容。[K04]
- 组织模板可供组织内成员在有编辑资格的空间使用；空间模板限本空间。另存模板、应用模板和模板编辑删除需保持模板范围，不能把组织模板可用性当作空间写权限。[K07]
- 页面历史支持查看、命名和恢复；恢复内容成为最新编辑内容。此处不能照搬“用例恢复一定新建版本”的规则，是否新增页面版本及版本 ID 行为要按实际契约确认。[K08]
- **页面导入和导出在本次手册正文均为开发中**。不得写成已提供的承诺；即使本地出现 PDF 等逻辑，也只能列候选能力并单独验证。[K09]

| T-F08 | 同一账号切换负责/参与/进行中待办，搜索、排序、筛选重置、列字段及导入导出 | 不同身份与不同库结果隔离；未授权数据不经筛选/导出绕过；通知不向不可读对象泄漏详情 |

| K-F02 | 作者保存草稿、关闭重开、发布、再次编辑，两个新会话分别读预览与草稿 | 未发布内容不进入公共预览/搜索/共享；发布不留下重复草稿，失败不丢草稿 |
| K-F03 | 作者新建父子页，复制含/不含子页、跨空间移动、删除及批量恢复 | 拒绝循环父节点/未授权目标；不遗漏子页；源/目标权限重算；原父缺失恢复有可解释结果 |
| K-F04 | 作者在三格式录入内容，附件/图片/代码/表格、选区评论与提及，刷新重入 | 格式往返无损；不执行恶意 HTML/链接；附件不能匿名/跨空间越权；提及不能授予读取权 |
| K-F05 | 管理员锁页面，作者、共享可编辑者、管理员分别尝试改正文与发布 | 全部遵守锁；不得只禁按钮；解锁需明确授权，历史恢复/改名等边界记录待定结果 |
| K-F06 | 分享者分别授权非成员查看/编辑，选择子页，撤销后从旧链接/通知/收藏重进 | 只读拒写；仅页面不扩到兄弟/空间；撤销立即拒绝旧令牌；锁优先于共享编辑 |
| K-F07 | 空间共享选择全部/子集、密码刷新及有效期，访客直接 URL/搜索/附件访问 | 错密码、旧密码、过期、关闭共享均拒绝；子集外不泄漏；公开页面不泄漏草稿与敏感共享设置 |

## 手册歧义与待办

1. T19 新用例“待评审”与本地代码表“待提交”需对齐术语和对象，评审计划/阶段/用例结果状态不能混用；T18/T20 对阶段完成与全计划完成的简写需补状态图。
2. T07 允许直接编辑评审状态与 T19/T20 计划驱动状态的优先级不明确；多计划并行、一通过一未通过、撤回与重新加入时的聚合规则待定义。
3. T16 基线名称唯一的范围、设立与用例更新并发的原子性、重复设立幂等、历史版本不创建后继的细节需确认。
4. T25 仅显示同计划最近记录不解释底层保留几条；T28 每日次数、重置未测、批量重复保存、跨天时区、已移出/已删用例是否计入均需明确，不能选最易实现的分母。
5. T28 “用例类型分布”的说明写成评审结果分布；“执行结果分布”的说明按执行人组织。需核对报表真实维度，不照搬错误描述。
6. T22 未说明通过率零分母、进度是否包含受阻/跳过及已完成计划能否重开；T27 测试报告正文很少，生成时机、权限、内容快照与重算规则均待补。
7. T04/T10 与 K04/K11 回收站未规定保留期限、永久删除、跨库/空间恢复冲突和整棵子树恢复规则；不可自行执行物理清理。
8. K04 说三种新建方式，但正文只明确普通/子页与模板；多人实时协作仅在概述声明，冲突处理、离线恢复、草稿可见主体与自动保存频率未定义。
9. K04 锁定后的解锁主体及改名/评论/附件/复制/恢复版本边界缺失；本地有解锁逻辑名称不代表手册允许何人使用。
10. K06/K10 共享撤销、过期、密码更新后旧会话/直链/附件的失效时效，页面/子页继承冲突与跨空间移动后共享是否保留，均需安全规格及负向测试。
11. K08 版本恢复后是否创建新 ID、自动版本粒度与命名权限未明；不能套用 T08 用例版本的明确规则。
12. K09 导入/导出明确开发中；本地存在导入元数据或 PDF 逻辑只能列候选，不应擅自把它写成正式支持。模板、评论、附件在各正文格式间的往返也待实际验收。
13. T30 “不关注”和“订阅”都描述为仅 @ 通知，但关注关系不同；重要操作通知范围、用户被移除后的通知处理需明确。
14. 手册正文含“附件/附近”“待办/代办”“模板/模版”等措辞差异；中英文固定术语应维护统一映射，不能据同义词猜成不同业务功能。
