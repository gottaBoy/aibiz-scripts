## 已定位的静态差异

### 测试通过率

`plm/model/PSSYSBISCHEMES/BIScheme.json` 和前端 BI 模型中的主指标，以全部计划执行用例
为分母，方向与手册一致。但以下两份逻辑的 `PassRate` 使用已执行数量：

- `plm/model/PSMODULES/TestMgmt/PSDATAENTITIES/run/PSDELOGICS/plan_compar_ative_analysis.json`
- `plm/model/PSMODULES/TestMgmt/PSDATAENTITIES/test_case/PSDELOGICS/plan_compar_ative_analysis.json`

这是本轮真实静态发现，**尚未判定这两个比较分析图表是否应表达不同指标**。
先检查展示名称、消费者、需求，再决定改 SQL 还是明确重命名，避免统一名字时改坏正确的另一口径。

### 零预估和空分母

主 BI 中存在以 `1` 替换零预估分母、为空集合防除零的实现。手册没有规定这套策略。
需单列“预估为零但实际非零”“两者为零”“没有工作项”算例并获得政策确认，不把当前代码
当成官方定义。发布平均周期的原文括号同样不足以决定计算顺序。

### 入口与统计范围

活跃成员逻辑可定位到昨日/七日计算，手册概览还要求近一个月图表；
须联查实际页面绑定的数据集，不只根据一个方法名称判缺失。
测试报告正文有标题/说明不一致处；必须对照真正输出和业务意图。
